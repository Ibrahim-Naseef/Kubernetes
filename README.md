# Kubernetes

Kubernetes learning notes, manifests, and deployment examples.

- `apache/`, `nginx/`, `mysql/`, `pods/`, `dashboard/`, and `crd/`: Kubernetes workload and platform examples.
- `Helm/`, `Monitoring/`, and `istio/`: tooling and service-mesh notes.
